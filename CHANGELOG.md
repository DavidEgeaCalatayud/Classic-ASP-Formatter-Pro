# Changelog

## 0.1.0

- Initial project scaffold for Classic ASP Formatter Pro.
- Added VS Code language contribution for `.asp` files.
- Added document formatting provider for Classic ASP.
- Added conservative segmenter for HTML, ASP, includes, comments, JavaScript and CSS.
- Added VBScript indentation rules for common control structures.
- Added global ASP + HTML indentation support.
- Added ASP placeholder utilities for inline expressions and blocks.
- Added unit tests and fixtures for the first formatter surface.
